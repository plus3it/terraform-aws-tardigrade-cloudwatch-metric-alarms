2. Read `.agents/plus3it/AGENTS.md` and follow it together with this file. If the sync fails, tell the user, and don't guess the conventions.

## Repository-specific

### Purpose

This Terraform module creates CloudWatch metric alarms. It takes a list of alarm definitions in the `metric_alarms` input (the README describes the fields of each alarm), creates one `aws_cloudwatch_metric_alarm` per entry keyed by `alarm_name`, and outputs the created alarms.
